# Findings report: September 2026 batch

Written 2026-11-06. What went wrong or was surprising in each source, and what was done about it. Results per chain are in `end-of-round-report-2026-09.md`.

## Derived files (requested by the owner to be documented)

- Chicken Cottage publishes five menu-board images (`BOXES.jpg`, `BURGERS.jpg`, `FRIED.jpg`, `GRILLED.jpg`, `SIDES.jpg`, 1920x1080) with calories only. The pipeline reads PDFs, so each image was converted with Pillow to a one-page PDF `inputs/ChickenCottage_<NAME>.pdf` (144 dpi, 960x540 pt) next to the original. The JPGs are untouched. The five derived PDFs are listed in `manifest` like any other file and have no text layer: every page is read by the model (`vision_table`) and read a second time (`reread`).

## Process findings

- Golden rows are picked by name over the whole chain, so a name that two sources share can give the other source's row; this happened five times (Pepperoni Campagna, Turmeric Shot, Tortilla's Cos Lettuce, a Cookhouse kids row, Vue's Club Lemon) and `eval` or a manual check caught each; the files were corrected (they were written in this batch).
- Where the text layer is intact, a free check that every returned figure is a token of the page text is stronger than a second model read (it found the Papa John's misread).
- The 5-hour model quota ran out once (about 11:34); finished pages are cached, so the runs resumed from the cache after the reset.
